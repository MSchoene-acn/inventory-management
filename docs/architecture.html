Factory Inventory Management System

Architecture overview: a Vue 3 dashboard over a FastAPI service backed by in-memory JSON data. No database.

System Architecture

Three tiers. The browser talks directly to the API over HTTP, and the API reads from data held in memory.

Frontend: Vue 3 single-page app

Vite dev server, http://localhost:3000
Dashboard / Inventory /inventory Orders /orders Demand /demand Spending /spending Reports /reports FilterBar + detail modals Composables: filters, auth, i18n (en / ja)
HTTP / JSON via axios (client/src/api.js), query-param filters

Backend: FastAPI REST API

Uvicorn, http://localhost:8001 (interactive docs at /docs)
Route handlers (main.py) Shared filter helpers Pydantic response models CORS middleware (all origins, demo only)
Python import at startup (server/mock_data.py)

Data: JSON files loaded into memory

server/data/*.json, reloaded on every server restart; changes do not persist
inventory orders demand_forecasts backlog_items purchase_orders spending transactions

Data Flow

How a filter change on screen becomes updated numbers and charts.

  1. User changes a filter. Four filters (time period, warehouse, category, order status) live in shared refs in useFilters.
  2. View reloads data. A watcher calls the matching method in api.js, which drops any filter set to all and builds the query string.
  3. Axios sends a GET request to http://localhost:8001/api/....
  4. FastAPI filters in memory. The handler applies warehouse, category and status filters, then a month filter for orders, over the already-loaded Python lists.
  5. Pydantic validates the response against the endpoint's response_model and returns JSON.
  6. The view updates. Raw results are stored in refs (such as allOrders and inventoryItems) and charts, tables and KPI tiles are derived from them in computed properties.

Key Design Notes

Deliberately simple persistence

  • Data is read once at startup, so edits to JSON need a server restart.
  • Filtering is plain Python list comprehension, which is fine for small demo data.

Known constraints

  • Inventory has no time dimension, so it ignores the month filter.
  • The API base URL is hard-coded in api.js.
  • No authentication, and CORS allows all origins, so this is for local use only.
  • Pydantic models must be updated whenever the JSON shape changes.
